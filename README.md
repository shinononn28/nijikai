# 二次会卓

TRPGの二次会で遊べる、チャット付きのブラウザパーティゲーム集です。
部屋を作って招待リンクを送れば、スマホでもPCでもすぐ遊べます。

## いま遊べるもの

- **被り列挙クイズ**(3〜12人):お題に合う言葉を制限時間内に好きなだけ書き、誰とも被らなければ+1、被ったら−1。表記ゆれ(カタカナ/ひらがな/全角半角など)は自動でまとめ、「同じでしょ」「お題外でしょ」は判定タイムに多数決で決めます。
- **月面基地の酸素**(4〜8人、CPUで人数調整可):毎日、共有タンクの酸素の使用量(1〜4)と、みんなに見せる宣言値を同時に決めます。使った分−1が得点。宣言は一斉公開され、「合計 − 宣言合計 − 監視件数」でその日の嘘の量だけがわかります。酸素を1余分に使えば1人の本当の使用量を監視でき、会議では過半数の投票で1人を隔離(翌日は使用量1で固定)できます。6日間もてば得点最多の人、途中で尽きたら総使用量が最少の人(脱出ポッド)の勝ち。
  - イベントは固定の山札(平穏2・隕石2・補給船・太陽嵐・夜間作業・節電命令・全数調査・通信障害)から毎日1枚、翌日の予報つき。
  - タンクの初期量は「人数×日数」、生産は毎日「人数〜人数×2」。全員の平均使用量が2なら7割ほど生き残る調整です。
  - 退室した人の席はCPUが引き継ぎます。
- **怪盗と探偵**(1〜6人、足りない探偵はCPU):毎回自動生成される街で、怪盗と探偵が同時に移動先を決める追跡ゲーム。怪盗は12ターン以内にお宝を3つ盗めば勝ち、探偵は同じマスに入るか同じ道ですれ違えば確保。
  - 怪盗の移動手段は毎ターン、位置はお宝を盗んだときと、ロビーで選んだターン(既定は4・8ターン目、3・6・9や「盗んだときだけ」も選べる)に公開。怪盗には変装(移動手段を隠す)×2と高飛び(2回移動)×1、探偵はバス4回・地下鉄2回まで。
  - 探偵だけの「作戦」チャットがあり、発言は設定した確率で伏せ字まじりに怪盗へ漏れる(盗聴)。作戦チャットには本物の目撃通報が届き、怪盗は同じ見た目の偽の通報を3回まで送れる。
  - 怪盗をCPUにすれば、全員で協力して追いかける遊び方もできる。
- **二枚舌**(1〜6人、卓は4〜6人でCPUが埋める):赤と青の陣営に分かれ、誰が味方かわからないままダイスの嘘を読み合う陣営戦ライアーズダイス。元の「二枚舌の酒場」のエンジンと画面をそのまま移植しています。
  - 卓での発言は二次会卓のチャット欄で行います。全体チャットの発言はそのまま卓の発言になり、CPUが反応したり推理の材料にしたりします。CPUの発言もチャット欄に流れます。
  - ゲーム内の「記録」ボタンで、ログ・手帳(自分だけの情報)・カードの使用状況を見られます。
- **小国の外交**(1〜6人、国は3〜6か国でCPUが埋める):自動生成の大陸で、全員が同時に命令を出して陣取り。
  - 命令は「隣の領地へ兵を動かす(攻撃・移動)」と「他の国の攻撃や守備への援軍」。戦闘は兵の合計+サイコロ(0〜2)で、同点は守備側の勝ち。援軍は戦闘後に元の領地へ戻る。
  - 不可侵条約はお互い守れば両国に平和配当(兵+1、2条約まで)、片方だけ攻めれば奇襲(+2)、両方攻めれば共倒れ(次の増援−2)。破った条約は公開され、同じ相手とは2ラウンド結び直せない。
  - ★の4割で即勝利(同じラウンドに複数の国が届いたら ★の数→領地の数→兵の数 で比べる)。全ラウンド終了時は 点数(★+秘密の目標)→★の数→領地の数→兵の数 の順で比べ、最後まで同じなら同率で勝ち。領地をすべて失った国は、トップの国の手薄な場所で反乱軍として再起(兵4+ラウンド数の半分、隣の領地も1つ取り、そのラウンドは攻撃を受けない)。
  - 人間どうしは1対1の「密談」チャットを使える。
- **ダンジョン合流**(2〜6人、協力、CPUの仲間を足せる):7×7の迷宮でバラバラの部屋から出発し、チャットで様子を伝え合って全員が同じ部屋に集まる。全1〜3階。
  - 見えるのは自分の部屋の目印・扉・扉の向こうの気配(水の音、光など)と、自分が歩いた地図だけ。深い階ほど目印の種類が減って紛らわしくなる。
  - 松明はチーム共有で1部屋1本(その階の「最短で集まれる歩数」の約2.4倍+8本)。徘徊する魔物に出くわすと松明3本を落として隣の部屋へ逃げる。残った松明の割合でS〜Cのランク。
  - 方角は「1階だけあり」「ずっとあり」「ずっとバラバラ(各自の画面が回転していて前後左右しかわからない)」から選べる。
  - CPUの仲間は動けない負傷者で、迎えに行くとついてくる。定期的に様子を報告するか、黙っているかを選べる。
  - 「部屋の様子をチャットに貼る」ボタンで、今の部屋の説明を自分の向きで自動的に書き込める。チョークで部屋に自分の色の印を残せる(各階3回)。

## ローカルで動かす

```bash
npm install
npm run dev     # 1人でも開始できるテストモード(http://localhost:3000)
npm start       # 本番と同じ設定
```

複数人の動作確認は、別のブラウザやシークレットウィンドウで同じ招待リンクを開くと手軽です。

## Render に公開する

1. このフォルダを GitHub のリポジトリに push します。
2. Render のダッシュボードで **New → Web Service** を選び、リポジトリを指定して次のように設定します。
   - Runtime: Node / Build Command: `npm install` / Start Command: `npm start` / Instance Type: Free
   - Health Check Path(Advanced): `/healthz`
   - 環境変数は不要です(`DEV_MIN_PLAYERS` はローカルの1人テスト用なので設定しないでください)
3. デプロイが終わると `https://〜.onrender.com` のURLで遊べます。以降は GitHub に push するたびに自動で再デプロイされます。

### 無料プランの注意点

- 15分ほどアクセスがないとサーバーが眠り、次に開いたときの起動に1分ほどかかります。二次会の前に一度開いておくと安心です。
- 部屋やチャットはサーバーのメモリにだけ保存しているので、再デプロイやスリープで消えます(プレイ中に push しないこと)。

## 構成

```
server.js              部屋・チャット・ゲーム選択(Express + Socket.IO)
games/index.js         ゲーム一覧。新しいゲームはここに登録する
games/kaburi.js        被り列挙クイズのルール(サーバー側)
games/kaburi-topics.js お題の素材(カテゴリ・頭文字)。行を足すとお題が増える
games/moon.js          月面基地の酸素のルールとCPU(数値の調整は冒頭の EVENTS / DECK と MoonGame)
games/kaito.js         怪盗と探偵のルールとCPU(公開ターンやチケット数は冒頭の定数)
games/kaito-map.js     怪盗と探偵の街の自動生成
games/nimaijita.js     二枚舌を部屋・チャットにつなぐアダプター
games/gaikou.js        小国の外交のルールとCPU(条約の数値は冒頭の定数)
games/meikyu.js        ダンジョン合流の迷宮生成とルール
public/app.js          画面の土台(ホーム・ロビー・チャット)
public/games/kaburi.js 被り列挙クイズの画面
public/games/moon.js   月面基地の酸素の画面
public/games/kaito.js  怪盗と探偵の画面(地図はSVG)
public/games/nimaijita-engine.js 二枚舌のルールとCPU(元のエンジン。stop() と発言テキストの追加のみ変更)
public/games/nimaijita.js        二枚舌の画面(元の画面を Shadow DOM の中に移植)
public/games/gaikou.js           小国の外交の画面
public/games/meikyu.js           ダンジョン合流の画面
public/style.css       見た目
```

### ゲームを追加するには

1. `games/` にルールのファイルを作り、`create(ctx, settings, playerIds)` で次のメソッドを持つオブジェクトを返します。
   - `action(playerId, type, payload, { isHost })` プレイヤーの操作
   - `view(playerId)` そのプレイヤーに見せる情報(手札など非公開情報はここで出し分ける)
   - `onJoin(id)` / `onLeave(id)` / `onConnectionChange()` / `dispose()`
   - 状態が変わったら `ctx.update()`、チャットへのお知らせは `ctx.system(text)`、終わったら `ctx.finish()`
   - 特定の人にだけ届けるメッセージは `ctx.post(msg, readers)`、CPUの発言は `ctx.say(id, name, text)`
   - 状態とは別に届けたい演出やログは `ctx.emitTo(playerId, type, data)`(画面側の `onEvent(type, data)` に届く)。再接続時に送り直すものは `backlog(playerId)` で返す
   - 全体チャットの発言をゲームで使うなら `onPublicChat(playerId, text)`
   - チーム用チャンネルを作るなら `chatChannels(playerId)` / `chatChannel(playerId, channel)` / `onChat(playerId, channel, text)` を実装する(怪盗と探偵が例)
2. `games/index.js` の `catalog` に登録します(`settings` を書くとロビーに設定欄が自動で出ます)。
3. `public/games/<ゲームID>.js` に画面を作り、`window.GameClients[ゲームID] = { create(root, api) }` で登録します。画面ファイルは遊ぶときに自動で読み込まれるので、`index.html` を触る必要はありません(複数ファイルが要るときは、`games/` の定義に `client: ['a.js', 'b.js']` を書く)。
